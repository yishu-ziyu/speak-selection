# 划词朗读

在网页上划一个单词或一句话，立刻听到它怎么读。

适合学英语、中文或其他语言：不用复制到别的 App，也不用离开当前页面。声音来自 [MiniMax](https://platform.minimax.io) 的语音合成。

> 这是 Chrome 扩展，目前需要手动加载，还没上应用商店。

## 你需要准备

- 电脑版 Chrome（Edge 等 Chromium 浏览器通常也可以）
- 一个 MiniMax API Key
  - 打开 [MiniMax 开放平台](https://platform.minimax.io) → 登录 → 创建 API Key
  - 语音按平台计费，以控制台余额 / 套餐为准

扩展**不会**把 Key 上传到本仓库或任何第三方。Key 只存在你这台电脑的 Chrome 里。

## 安装

### 1. 下载扩展

任选一种：

```bash
git clone https://github.com/yishu-ziyu/speak-selection.git
```

或在 GitHub 页面点绿色的 **Code → Download ZIP**，解压到任意目录。记住这个文件夹的位置。

### 2. 加载到 Chrome

1. 地址栏打开 `chrome://extensions`
2. 右上角打开 **开发者模式**
3. 点 **加载已解压的扩展程序**
4. 选中刚才的 `speak-selection` 文件夹（里面能看到 `manifest.json`）
5. 固定到工具栏，方便点图标

加载成功后，工具栏会出现一个深色喇叭图标。

### 3. 填入 API Key

1. 点工具栏图标，再点 **打开设置**
   （也可以在扩展卡片上点 **详细信息 → 扩展程序选项**）
2. 把 MiniMax API Key 粘贴进去
3. 点 **保存并试听**

能听到试听句，就说明装好了。听不到的话，看文末「常见问题」。

## 怎么用

打开任意普通网页（新闻、维基、文章、文档站点都可以）。

1. **用鼠标划选** 一个单词或几句话
2. 选区附近会出现一条黑色朗读条
3. 点金色 **播放** 按钮：按正常速度读
4. 点 **慢**：更慢，方便跟读
5. 点方块：停止
6. 读完或停止后，朗读条会自己收起

还可以：

| 方式 | 操作 |
|------|------|
| 右键菜单 | 划选后右键 →「朗读选中文本」或「慢读选中文本」 |
| 快捷键 | `Alt+S`（Mac 是 `Option+S`）朗读当前选区；`Alt+Shift+S` 停止 |
| 工具栏弹窗 | 点扩展图标，直接输入单词或句子试听，不必先打开网页 |

快捷键如果没反应，到 `chrome://extensions/shortcuts` 看有没有被别的扩展占用，改成你习惯的组合即可。

## 设置里可以改什么

在选项页可以改：

- **音色**：中文、英语、日语、韩语、粤语等系统音色；也可以填自己的 MiniMax 克隆 `voice_id`
- **模型**：默认 `speech-2.8-hd`（更清楚，适合跟读）。想更快可以换成 Turbo
- **语种增强**：默认「自动检测」。学某一门语言时，也可以锁成英语 / 中文 / 日语等
- **语速、音量、音高**
- **划词后自动朗读**：默认关闭，避免误触

学英语建议：语种增强选「英语」，音色选 English 分组里的任意一个。
学中文建议：语种增强选「中文」，音色选中文分组。

列表里如果出现某个克隆音色，那是某个账号自己训练的，**只有创建它的 MiniMax 账号能用**。别人请选系统音色，或把自己控制台里的 `voice_id` 填进「自定义」。

## 更新

以后拉取新版本后，回到 `chrome://extensions`，点这个扩展的 **重新加载**。不必卸载重装。Key 和偏好会留在 Chrome 里。

```bash
cd speak-selection
git pull
```

## 常见问题

**划了字但没有朗读条？**
确认扩展已开启，并且当前不是 Chrome 自带 PDF、`chrome://` 或 Chrome 网上应用店页面。这些页面不允许扩展注入。刷新网页再试一次。

**点了播放没声音？**
先去设置页点「保存并试听」。若试听也失败：检查 Key 是否完整、账号是否还有额度、网络是否能访问 MiniMax。克隆音色读不出来时，换成「暖心闺蜜」或「Expressive Narrator」再试。

**快捷键没用？**
到 `chrome://extensions/shortcuts` 给「划词朗读」重新指定按键。

**一次能读多长？**
默认最多约 2000 字，更长会截断前半段。可在设置里调高，上限 10000。

**会不会把我划的句子传到别的地方？**
文本只会发到 MiniMax 的官方语音接口用来合成，Key 只存在本地 Chrome。本项目不运营账号系统，也没有自己的服务器收你的内容。
